mochi — experiment workbench

Open the current prototype

Every version of the prototype, and the record of what each one was testing. Each version keeps its own link, its evidence, and its own document. Decisions carry a stable id, so a new version is a new set of results against the same questions rather than a fresh page that quietly discards what came before.

Nothing here is hidden. A rejected option stays listed with the reason it was rejected, and a version that is superseded stays readable so the two can be compared. Where there is no evidence yet, the field says so rather than filling the gap.

How to direct me

Versions and decisions both have ids. A version is proto1; a decision inside it is proto1/data-view/trend-line. Append a solution key to name one option rather than the whole decision.
